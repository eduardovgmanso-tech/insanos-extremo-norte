# Painel Insanos (nuvem) — repositório de TESTE

O painel é gerado aqui pelo GitHub Actions, lendo a planilha do Google.
Nada de dados pessoais fica neste repositório: as chaves ficam em Settings > Secrets, e a planilha é lida só durante a execução.

Para gerar: aba **Actions** > **Painel Insanos (nuvem)** > **Run workflow**.
